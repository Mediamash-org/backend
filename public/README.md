# OMSS Console UI

Sample frontend for this host (not part of the OMSS protocol).

## Open

With the server running (`npm run dev`):

[http://localhost:3000/ui](http://localhost:3000/ui)

## Features

- List providers from `GET /admin/providers`
- Enable / disable providers
- Reload plugins
- Resolve movie / TV sources by TMDB id
- Play proxied HLS (hls.js) or MP4 in-browser
- Show diagnostics from provider responses
