# Security Policy

## Supported versions

Security fixes are applied to the latest release on the default branch and to the newest `v*` Docker tag on GHCR when practical.

| Version | Supported |
|---------|-----------|
| Latest `main` / newest `vX.Y.Z` | Yes |
| Older releases | Best effort |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems (open proxy abuse, auth bypass, RCE, dependency exploits, etc.).

1. Use **GitHub → Security → Advisories → Report a vulnerability** on this repository (enable private reporting in repo settings if needed), **or**
2. Email the maintainers listed on the org profile once the organization is created.

Include:

- Affected version / image digest
- Steps to reproduce
- Impact (what an attacker gains)
- Any suggested fix

You should receive an acknowledgement within a few days. Please give us reasonable time before public disclosure.

## Non-security bugs

Use the public issue tracker with the Bug report template.
