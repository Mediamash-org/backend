# Support MediaMash

Ways to help the project and get help yourself.

## Get help

1. Read [docs/DEPLOYMENT.md](./docs/DEPLOYMENT.md) (`PUBLIC_URL`, Docker, TLS).
2. Search [GitHub Issues](../../issues) for your error / provider name.
3. Open a new issue with the **Bug report** template:
   - OMSS version or image tag (`ghcr.io/…`)
   - `PUBLIC_URL` / how you reach the server
   - Sample TMDB id and `/v1/movies/{id}` response summary (redact tokens)
4. Provider authoring questions → [docs/PROVIDER_PLUGIN_GUIDE.md](./docs/PROVIDER_PLUGIN_GUIDE.md) or a **Provider idea** issue.
